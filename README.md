# Mini Projects – Machine Learning & Web Applications

This repository contains a collection of **mini projects focused on Machine Learning, data preprocessing, model training, and web-based deployment**.  
Each project is designed to demonstrate practical ML workflows, from data handling to model evaluation and application-level integration.

The projects are implemented using **Python, scikit-learn, Flask, and Streamlit**, with an emphasis on clean structure and reproducibility.

---

## Projects Overview

### 1️ Car Price Prediction
**Problem Type:** Regression  
**Objective:** Predict the resale price of a car based on its features.

**Highlights:**
- Feature engineering and data preprocessing
- Multiple regression models evaluated
- Hyperparameter tuning for improved performance
- Model persistence using pickle

📁 Folder: `01-car-price-prediction`

---

### 2️ Boston House Price Prediction
**Problem Type:** Regression  
**Objective:** Estimate median house values using socio-economic and structural indicators.

**Highlights:**
- Classical Boston Housing dataset
- Feature scaling and engineered features
- Gradient Boosting Regression model
- Professional Streamlit-based user interface

📁 Folder: `02-boston-houseprice`

---

### 3️ Loan Approval Prediction
**Problem Type:** Classification  
**Objective:** Predict whether a loan application will be approved or rejected.

**Highlights:**
- Binary classification problem
- Handling of categorical and numerical features
- Label encoding and preprocessing pipeline
- Flask-based web application for prediction
- End-to-end training and deployment workflow

📁 Folder: `03-loan-approval-prediction`

---

### 4️ Wine Quality Classification
**Problem Type:** Classification  
**Objective:** Classify wine samples based on physicochemical properties.

**Highlights:**
- Supervised classification models
- Feature scaling and encoding
- Model evaluation using accuracy and confusion matrix
- Clean, structured ML training pipeline

📁 Folder: `04-wine-quality-classification`
